## JEE Key Points — Revision Summary

### Must Remember
- EM waves are **transverse** and do **not require a medium**
- **E** and **B** are perpendicular and **in phase**
- Velocity in vacuum: $c = 3 \times 10^8 \, m/s$
- Intensity: $I = \frac{1}{2} \epsilon_0 c E_0^2 = \frac{1}{2\mu_0} c B_0^2$
- Radiation pressure: $P = I/c$ (absorption), $P = 2I/c$ (reflection)
- Photon energy: $E = h\nu$

### Common Traps
- Forgetting that E and B are **in phase**
- Confusing $c$ (vacuum) with $v$ (medium)
- Using the wrong formula for absorption vs reflection pressure
- Mistaking intensity (∝ E₀²) with amplitude (∝ E₀)

### Application Questions
1. Given E₀, find B₀: use $B_0 = E_0 / c$
2. Given intensity, find radiation pressure
3. Given wavelength, find photon energy: $E = hc/\lambda$
