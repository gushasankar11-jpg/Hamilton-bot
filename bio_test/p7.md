# Nucleic Acids & Hormones

## Nucleic Acids
- **Polymers of nucleotides**
- **Nucleotide** = nitrogenous base + sugar + phosphate
- **Nucleoside** = base + sugar (no phosphate)

### Components

| Component | RNA | DNA |
| --- | --- | --- |
| Sugar | **Ribose** | **Deoxyribose** |
| Bases | A, G, C, **U** | A, G, C, **T** |
| Strands | Single | Double |
| Function | Protein synthesis | Genetic info storage |

### Nitrogenous Bases
- **Purines**: Adenine (A), Guanine (G) — 2 rings
- **Pyrimidines**: Cytosine (C), Thymine (T), Uracil (U) — 1 ring

### DNA Double Helix
- Two strands wound around each other
- **Base pairing**: A-T (2 H-bonds), G-C (3 H-bonds)
- Discovered by **Watson & Crick**

### RNA Types
- **mRNA**: messenger — carries genetic code
- **tRNA**: transfer — brings amino acids
- **rRNA**: ribosomal — part of ribosome

## Hormones
- **Chemical messengers** secreted by endocrine glands
- Travel through blood to target organs

| Hormone | Gland | Function |
| --- | --- | --- |
| Insulin | Pancreas | Lowers blood sugar |
| Thyroxine | Thyroid | Metabolism regulation |
| Adrenaline | Adrenal | Fight-or-flight response |
| Testosterone | Testes | Male characteristics |
| Estrogen | Ovary | Female characteristics |

## JEE PYQ Key Points
- **Reducing sugars**: glucose, fructose, maltose, lactose — NOT sucrose
- **Anomers**: differ at C1 (glucose) or C2 (fructose)
- **Essential amino acids**: 9 in number — cannot be synthesised by body
- **Peptide bond**: -CO-NH-, has partial double bond character
- **Denaturation**: 2°/3°/4° structure lost; 1° structure intact
- **DNA base pair rule**: A=T and G≡C → Chargaff's rule
- **Vitamin C**: L-ascorbic acid — water-soluble, prevents scurvy
- **Sucrose is non-reducing** because both anomeric carbons are blocked
- **Glycosidic bond** joins two monosaccharides
